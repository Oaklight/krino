# Probing

We ran 21 systematic probes against the Jev API (jev-1.13.0), totaling ~5,620 API calls across 3 rounds of behavioral probing and 5 preregistered controlled experiments (3,757 requests). Each round included a rigor self-audit, and flawed probes were re-designed and re-run.

## Sections

- [**API Testing**](api-testing.md) — Initial exploration of all three Jev primitives (noul, choice, score), request/response schema, and baseline observations
- [**Architecture Analysis**](architecture.md) — Comprehensive architecture fingerprinting through behavioral and controlled probes, hypothesis evaluation, and identified operational pipeline
