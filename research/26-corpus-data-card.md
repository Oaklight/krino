# Canonical corpus data card — 2026-11-06

One page for the training arm. Definitions and per-file provenance are in
`research/25-corpus-inventory.md`.

Two sources of numbers, kept separate so the card stays auditable:

- **Generated by `scripts/corpus_datacard.py`:** corpus sizes after dedup
  (`by_corpus`), tier, origin, type mix, choice-K, score levels, state length,
  and the three hard-label counters.
- **Carried from `research/25` or one-off counts:** the pre-dedup sum and its
  decompositions, the label-file row/id/duplicate figures, the coercion counts,
  the contamination audit, and the gap list.

The corpora are not in the repository, so a reader cannot regenerate the numbers
from the script alone. Run it against a data mirror; the card's generated section
should match the JSON exactly.

## Terms and licences

**ANLI is CC BY-NC 4.0 (non-commercial).** It is the only source in this corpus
with a verified non-permissive term. The canonical corpus contains at least 1,239
ANLI-derived records:

- 473 in target 30K (`source: anli`);
- 568 in residual 20K (`source: anli`);
- 198 abstention records whose own `source` is `anli`.

The abstention `out_of_scope` construction borrows a state from a different
source, so an ANLI state can also appear on a record whose `source` is not
`anli`; 1,239 is therefore a lower bound. These rows are restricted to
non-commercial use unless separately cleared, and must be removed or cleared
before any commercial use.

Everything else is **not audited**, not cleared. Absence of a term in this table

## Known gaps

The corpus covers classification/choice, boolean judgment (noul), and ordinal
scoring, plus tool selection, long-context choice, and constructed abstention.
It does not contain first-class training data for:

- ranking/reranking and retrieval pairs (no pairwise margin data);
- structured extraction and per-field verification;
- multi-question states sharing one state (batch equivalence);
- hierarchy / taxonomy selection;
- self-consistency and multi-sample agreement targets;
- continuous-score regression (scores are 3-6 levels);
- large-K selection above K=80 (the head supports 255).

Vision and image inputs are out of scope for the current arm. Date and count
arithmetic are handled in code, not in the corpus.

## Reproduction

```bash
python scripts/corpus_datacard.py \
  --root data/benchmarks --repo-root . --json /tmp/datacard.json
```

If `typed_decisions.jsonl` sits outside `--root`, pass
`--typed-decisions <path>`. The script is single-process, stdlib-only apart from
`data.provenance` and `data.synthetic.family_to_typed_questions`. It exits if a
primary file is missing, so a partial mirror cannot silently produce a smaller
card.
